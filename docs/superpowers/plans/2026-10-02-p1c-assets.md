# P1c Storage und Assets – Plan

Spec: `docs/superpowers/specs/2026-10-02-p1-graph-metadata-assets-design.md` Abschnitt 5.

## Coworkee

- `Coworkee.Storage`: `IBlobStorage` (FileSystem, S3, AzureBlob über `Coworkee:Storage:Provider`), `BlobKeys`, `BlobLinks` (ablaufende Tokens über DataProtection). Contract-Tests gegen Dateisystem, s3mock und Azurite.
- `Coworkee.BackgroundJobs`: `AddRecurringJob<TJob>(id, cron)` für Jobs ohne Tenant.

## Shareme.Assets

- Global geseedet: `AssetType` (image, video, audio, document, archive, other), `FileType` (Endung, Mime, AssetType, verboten, Magic Numbers).
- `Asset` (Graph, TPH-Spalten): `AssetTypeKey`, `CurrentVersionId`, `Status` (Importing, Ready, Duplicate).
- `AssetVersion { AssetId, Number, FileName, Size, Sha256, MimeType, Extension, BlobKey, MetadataSnapshot }`, Cascade mit dem Knoten.
- `UploadSession { TargetFolderId | AssetId, FileName, Size, Sha256?, ChunkSize, Received[], UserId, ExpiresAt }`, Chunks als Blobs `{tenant}/uploads/{session}/{n}`.
- Ablauf: Start (Rechte Create am Ordner bzw. Update am Asset, verbotene Endung abgelehnt), Chunks (nur Ersteller, ≤ 8 MB, Index im Bereich), Complete (alle Chunks da, über eine Temp-Datei zusammensetzen und hashen, Größe und Hash prüfen, Magic Number prüfen, Blob schreiben, Asset bzw. Version anlegen, bei neuer Version Metadaten-Snapshot der Vorversion und `IgnoreOnNewVersion`-Keys entfernen, Duplikate mit gleichem Hash im Tenant als Edge `duplicate`, Domain-Event `AssetVersionCreated`).
- Download: `GET /api/v1/assets/{id}/download?version=` mit `Assets.Download`; `POST /api/v1/assets/{id}/download-link` liefert eine ablaufende URL `GET /api/v1/blobs/{token}` ohne Anmeldung.
- Aufräumen: `OrphanBlob`-Tabelle; Purge trägt die Blob-Keys gelöschter Versionen in derselben Transaktion ein (Hook `INodePurgeListener` in Graph); wiederkehrender Job löscht verwaiste Blobs und abgelaufene Upload-Sessions samt Chunks.

## Nicht in P1c

Derivate, Vorschau und die Upload-UI (P1d), System-Properties im Metadaten-Katalog (Werte stehen im Asset-DTO), Zip-Download (P3).
