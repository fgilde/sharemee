      § 1

      What it is built to do

      1. Assets with historyChunked uploads, versions, thumbnails, previews, print renditions, watermarks, crops, video and 3D. Shown with MudExFileDisplay.
      2. Your own data modelEntity types, relations and fields with lists, languages and market contexts. Required fields per form, values inherited from folders.
      3. Permissions per itemRoles and groups granted on any folder or file, inherited downwards, stoppable where a branch needs its own rules.
      4. Audit on every fieldWho changed what from which value to which. Pages, templates and settings keep restorable versions.
      5. WorkspacesKanban states, tasks, comments with mentions, watchers, notifications and shares for people outside.
      6. Knowledge and intranetVersioned wiki pages with diffs, news, a start page of widgets and a people directory, all in one search.
      7. Realtime by defaultOne generic SignalR channel. Lists, details, jobs and notifications refresh themselves.
      8. REST, Swagger, MCPEverything is an API first. An MCP endpoint and a built-in assistant act strictly as the user who calls them.

      § 3

      How it is put together

      WebBlazor Web App with MudBlazor. Holds the login, the browser never sees a token.
      AuthOpenID Connect server for users, tenants, two-factor and external logins.
      APIREST with OpenAPI, the SignalR hub and the MCP endpoint.
      ProcessingBackground jobs for renditions, metadata extraction and imports.
      CoworkeeThe framework underneath: modules, permissions, settings, mail templates, audit, realtime. Separate NuGet packages.
      Postgres · Redis · ElasticsearchData, cache and realtime backplane, search. Started by .NET Aspire.
      § 4

      Run it

      .NET 10 SDK and Docker. Until Coworkee is on NuGet, its repository sits next to this one in a folder named coworkee.

      # pack Coworkee into the local feed
pwsh coworkee/build/pack-local.ps1

# start everything under Aspire
dotnet run --project sharemee/src/Shareme.AppHost
